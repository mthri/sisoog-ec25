# کدهای آموزشی و پروژه‌های ماژول Quectel EC25 (سیسوگ)

این مخزن شامل کدها، اسکریپت‌ها و پروژه‌های پیاده‌سازی‌شده مرتبط با مجموعه مقاله‌های آموزشی ماژول **Quectel EC25** است که توسط من در وب‌سایت [سیسوگ (Sisoog)](https://sisoog.com/author/a-motahari98/) منتشر شده‌اند.

---

---

## سخت‌افزار و پیش‌نیازهای عمومی

* **ماژول مخابراتی:** Quectel EC25-EUX (اتصال از طریق درگاه USB / Mini PCIe to USB Adapter)
* **سیستم‌عامل:** لینوکس (تست‌شده روی توزیع‌های مبتنی بر دبیان و اوبونتو)
* **پایتون:** نسخه 3.10 یا بالاتر
* **آنتن‌ها:** آنتن سلولار LTE مناسب و سیم‌کارت با اعتبار فعال
