## سخت‌افزار و پیش‌نیازهای عمومی

* **ماژول مخابراتی:** Quectel EC25-EUX (اتصال از طریق درگاه USB / Mini PCIe to USB Adapter)
* **سیستم‌عامل:** لینوکس (تست‌شده روی توزیع‌های مبتنی بر دبیان و اوبونتو)
* **پایتون:** نسخه 3.10 یا بالاتر
* **آنتن‌ها:** آنتن سلولار LTE مناسب و سیم‌کارت با اعتبار فعال

## دستیار صوتی فارسی (`02-ai`)

این بخش با میکروفون و بلندگوی سیستم کار می‌کند و در اجرای فعلی به ماژول EC25 یا سیم‌کارت نیاز ندارد. پس از آماده‌شدن مدل‌ها، برنامه صحبت شما را دریافت می‌کند، میکروفون را می‌بندد و متن را به LLM می‌فرستد. پاسخ به‌صورت جمله‌به‌جمله در یک ترد جدا به صوت تبدیل می‌شود و هم‌زمان تکه‌های آماده پخش می‌شوند. پس از پایان پاسخ، میکروفون دوباره فعال می‌شود.

برای نصب وابستگی‌های این بخش:

```bash
cd 02-ai
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

فایل `requirements.txt` فقط پکیج‌های اصلی مورد نیاز را شامل می‌شود؛ زیر‌وابستگی‌ها توسط `pip` به‌صورت خودکار نصب می‌شوند. نسخهٔ پایتون باید با بسته‌های این بخش سازگار باشد.

پیش از اجرای `python main.py`، مدل‌های STT و TTS را دانلود و Ollama را آماده کنید. مراحل کامل نصب، تغییر مسیرهای `farsi.yaml`، معرفی فایل‌ها و راهنمای جایگزینی `example_voice.wav` با صدای خودتان در [README بخش دستیار صوتی](./02-ai/README.md) آمده است.
