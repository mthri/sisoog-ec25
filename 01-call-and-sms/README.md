# کنترلر تماس و پیامک Quectel EC25 (بخش ۰۱)

این پوشه شامل کدهای مدیریت تماس صوتی، دریافت و ارسال پیامک متنی/فارسی (UCS-2) و برقراری پل صوتی دوطرفه برای ماژول **Quectel EC25-EUX** در لینوکس است. داده‌ها با استفاده از Peewee ORM در پایگاه داده SQLite ذخیره می‌شوند.

بخشی از مجموعه آموزشی: [sisoog-ec25](https://github.com/mthri/sisoog-ec25)

---

## مقایسه نسخه‌ها

| قابلیت | نسخه ۱ (`main_v1.py`) | نسخه ۲ (`main_v2.py`) |
| --- | --- | --- |
| **نوع عملکرد** | متنی و سبک (Headless) | تعاملی با انتقال صدای مکالمه |

| **وابستگی‌های سیستم** | حداقل نیازمندی (`pyserial`, `peewee`) | نیازمند پکیج صوتی PortAudio و `sounddevice` |

## سخت‌افزار و پورت سریال

ماژول EC25 در لینوکس چندین پورت سریال مجازی ایجاد می‌کند:

* `/dev/ttyUSB0` -> پورت عیب‌یابی (DM / Diagnostic)
* `/dev/ttyUSB1` -> داده‌های موقعیت‌یابی ماهواره‌ای (GNSS / NMEA)
* `/dev/ttyUSB2` -> **پورت اصلی دستورات AT و اعلان‌های URC** (مورد استفاده در این پروژه)
* `/dev/ttyUSB3` -> اتصالات داده (PPP)

## راه‌اندازی و پیش‌نیازها

### ۱. دسترسی به پورت سریال

```bash
sudo usermod -aG dialout $USER
# یک‌بار از سیستم خارج شده و مجدداً وارد شوید

```

### ۲. نیازمندی‌های سیستم (فقط برای نسخه ۲)

برای اجرای نسخه ۲ که به کارت صدای سیستم و ماژول وصل می‌شود، پکیج‌های PortAudio را نصب کنید:

```bash
sudo apt update
sudo apt install libportaudio2 portaudio19-dev

```

### ۳. کلون و نصب پکیج‌های پایتون

```bash
git clone https://github.com/mthri/sisoog-ec25.git
cd sisoog-ec25/01-call-and-sms

python3 -m venv .venv
source .venv/bin/activate

# نصب وابستگی‌های نسخه ۱:
pip install pyserial peewee

# یا نصب تمام وابستگی‌ها برای اجرای هر دو نسخه:
pip install pyserial peewee sounddevice

```

### دستورات خط فرمان (CLI)

| دستور | توضیحات | مثال |
| --- | --- | --- |
| `status` | نمایش اپراتور، تکنولوژی شبکه و کیفیت سیگنال | `status` |
| `call <number>` | شماره‌گیری تماس صوتی خروجی | `call 09123456789` |
| `answer` | پاسخ دادن به تماس دریافتی جاری | `answer` |
| `hangup` | قطع تماس فعال یا رد تماس دریافتی | `hangup` |
| `sms <number> <text>` | ارسال پیامک فارسی یا انگلیسی | `sms 09123456789 سلام تست` |
| `logs` | نمایش آخرین تماس‌ها و پیامک‌های ذخیره‌شده | `logs` |
| `help` | نمایش راهنمای دستورات | `help` |
| `exit` | خروج ایمن و بستن نشست پورت سریال | `exit` |

## نکات فنی

* **پردازش پیامک فارسی:** پیامک‌ها در صورت داشتن حروف غیرلاتین، به کدگذاری ۱۶ بیتی UCS-2 تبدیل شده و با هگزادسیمال ارسال می‌شوند. تنظیمات کاراکتر ماژول بعد از ارسال فوراً به حالت `GSM` بازمی‌گردد تا ظرفیت پیامک‌های بعدی به ۷۰ کاراکتر محدود نشود.
* **دیکد خودکار نام فرستنده:** اگر فرستنده پیامک متنی باشد (مانند بانک‌ها یا سرویس‌های خدماتی)، رشته‌های زنجیره‌ای اسکی به متن خوانا تبدیل می‌شوند.
* **پل صوتی در نسخه ۲:** تماس‌ها از طریق دستور `AT+QPCMV=1,2` داده‌های صوتی PCM را با فرمت `8000Hz 16-bit Mono` روی کارت صدای USB ماژول فعال می‌کنند و با بسته شدن تماس یا دریافت `NO CARRIER` بافرها و استریم‌های صوتی متوقف می‌شوند.
